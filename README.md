# ML Playground

This repository is a compilation of my go-to learning and experimenting with Machine Learning projects and notebooks. It serves as an all-in-one machine learning testing and playground environment.

## Repository Structure

The project is organized into the following directories to keep the workflows clean and accessible:

* **data/**: Contains the datasets used across different projects.

* **notebooks/**: Stores all Google Colab and Jupyter notebooks for testing and experimentation.
* **scripts/**: Holds helper tools, utility functions, and standalone Python files.

## Getting Started

To work with any notebook in this repository:

1. Navigate to the `notebooks/` directory.
2. Select the notebook you want to explore.
3. Open it directly in Google Colab or download it in your local Jupyter Notebook setup to run or edit the code.
